# AUDIT — 2026-08-11 (second audit, post-v2.0.0)

Gold-standard completeness audit of this repository as an artifact: a published standard and the
machinery around it. **AUDIT only** — no rule was filled, adopted, or conformed, and no file other
than this one was written for this topic.

## Conditions this audit ran under, stated before any number

This was a non-interactive caretaker run, and the environment refused every instrument that leaves
the machine:

- `WebFetch` and `WebSearch` — permission denied, no user present to grant it.
- `curl` via shell — "This command requires approval".
- `Invoke-WebRequest` — blocked by a command hook ("Command invokes .NET methods").
- `node` — blocked entirely ("requires approval", tried via Bash, PowerShell, and `rtk proxy`),
  which means **`tools/check.mjs` could not be run this session**. Its 6/6-green status is carried
  from the dispatch that started this run, not re-measured here.
- The auditing skill's own method reference (`references/method.md`) — permission denied; the audit
  ran on the skill's summary contract alone.

The consequence is honest and severe: **the exemplar-verified half of this audit did not run.**
Every criterion whose evidence is an external exemplar's live documentation is marked N-A below,
with this section as the justification. What remains is the internal half — every claim in it was
measured by reading the actual files in this working tree, and each row names the file it was read
from. A number measured by reading a file and a number that would have come from a fetched exemplar
are different kinds of evidence, and this report does not blur them.
